# Loon 配置与插件

个人 Loon 配置、插件、脚本与规则仓库。按目录管理，统一使用 `main` 分支。

| 目录 | 内容 |
| --- | --- |
| `plugins/` | 可直接导入 Loon 的插件 |
| `scripts/` | 插件引用的 JavaScript 脚本 |
| `configs/` | 配置示例与片段 |
| `rules/` | 分流规则 |
| `tests/` | 模拟 Loon 运行时的回归测试 |

## NodeSeek 自动签到

**仅允许 iPhone 执行。** 配置同步到 Mac 或 iPad 后，定时签到、手动签到、Cookie 获取和清除凭证均直接跳过，不发送通知、不读写凭证、不发起签到请求。HTTP 捕获脚本仍使用 `$done({})` 放行原始浏览请求。
设备依据 Loon 提供的 `$loon` 字符串判断；设备信息缺失或格式无法识别时默认跳过。此限制是脚本运行行为限制，不是防修改的设备认证。

[插件地址](https://raw.githubusercontent.com/kkdove2011/loon-config/main/plugins/NodeSeek.plugin)

1. 在 Loon 的插件管理中添加上述地址，开启插件及脚本功能。
2. 安装并信任 Loon 的 MitM 证书，开启 MitM；插件仅声明 `www.nodeseek.com`。
3. 在 NodeSeek 插件的参数设置中开启「获取 Cookie」（默认开启），用经过 Loon 的 Safari 登录 NodeSeek，完成网站验证后刷新首页。
4. 收到「已保存浏览器凭证」后，运行「NodeSeek 手动签到」，在论坛核对结果。
5. 验证成功后，在插件参数设置中关闭「获取 Cookie」；凭证失效时重新开启并登录获取。不要关闭整个插件。

若看不到「获取 Cookie」参数，先更新插件远程内容，再重新打开插件设置；仍加载旧内容时，可删除该插件条目后用同一插件地址重新添加（不会主动清除脚本本地凭证）。
「获取 Cookie」是插件 `[Argument]` 声明的可见开关，不是主配置中独立脚本的开关。

每日 08:00 按设备本地时区执行；当天完成记录按 UTC+8 日期判断。香港/中国时区的设备二者一致。
设备在调度时需允许 Loon 运行，iOS 后台调度并不保证精确触发。

| 脚本入口 | 行为 |
| --- | --- |
| Cookie 获取 | 保存 Cookie 与 User-Agent；凭证更新通知最多每 5 分钟一次 |
| 每日签到 | 随机奖励；当天已记录完成或存在执行锁时跳过，仅记录日志；成功和错误仍通知 |
| 手动签到 | 当天完成时跳过，并显示通知 |
| 强制核验 | 忽略本地当天完成记录，向网站再次请求；仍遵守执行锁 |
| 清除凭证 | 仅删除本插件凭证和每日完成记录 |

脚本参数支持 `key=value&key=value` 字符串和 Loon 参数对象：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `random` | `true` | 改为 `false` 时请求固定奖励；仅影响未来的签到 |
| `force` | `false` | 为 `true` 时忽略本地完成记录，不保证网站会重新发放奖励 |
| `quiet` | `false` | 为 `true` 时不通知「当天已完成」或「正在执行」，不隐藏错误 |
| `action` | 签到 | `clear` 删除凭证和完成记录 |

## 本次改进

- 修复 Loon 缺少或不可靠的 `clearTimeout` 导致收尾中断、执行锁残留的问题。
- 超时回调与网络回调互相去重，每次执行只调用一次 `$done`。
- 兼容对象参数、URL 编码参数和损坏的本地 JSON 数据。
- 凭证更新通知限频；定时跳过减少无意义通知。
- 新增强制核验和清除凭证入口；收紧「今日已签到」文字判断，避免把后续失败描述当作成功。
- 添加 iPhone 设备限制，配置同步到 Mac 后自动跳过所有入口。
- 保留上游的 UTC+8 当日去重、短期执行锁、固定域名请求、禁用重定向和 TLS 校验。

Cookie 保存在 Loon 本地，不写入仓库或日志。更换 Cookie 会重置当天记录，避免换号后被误跳过；不解析网站未公开的账号字段。
存储 Key 沿用上游 `nodeseek.loon.v2.state` / `nodeseek.loon.v2.lock`，已使用上游脚本的同一台设备无需迁移。
不要同时启用上游插件和本插件，以免重复调度或相互更新凭证。执行锁用于减少重叠请求，跨脚本存储不具备原子锁保证。

插件参数需要 Loon Build 733+，建议使用当前稳定版。脚本所用 HTTP API 需要 Build 662+。HTTP 超时 20 秒，脚本保护超时 25 秒，插件执行上限 35 秒。
请求沿用你的 NodeSeek 路由规则，不强制直连或指定节点。403/验证页面需在浏览器处理，脚本不绕过网站验证。

## 验证与维护

```sh
node --check scripts/nodeseek_checkin.js
node --test tests/*.test.cjs
```

测试使用模拟 Cookie、响应、存储和定时器，不访问网站、不执行真实签到。GitHub Actions 在推送和 PR 时运行同样的检查。
真实登录、网站签到接口和 iOS 调度需在 Loon 中验证。

来源及参考见 [SOURCES.md](SOURCES.md)。新增插件放入 `plugins/`，配套脚本放入 `scripts/`；配置和规则分别放入对应目录。
